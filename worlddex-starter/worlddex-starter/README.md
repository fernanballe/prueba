# 🌍 WorldDex — Paquete de Arranque

Bienvenido. Este paquete contiene **todo lo que necesitas** para empezar a desarrollar WorldDex con Claude Code, compilarlo e instalarlo en tu dispositivo móvil.

## 📂 Contenido del paquete

| Archivo | Para qué sirve | Cuándo usarlo |
|---------|---------------|---------------|
| **`00-EMPIEZA-AQUI.md`** | Guía paso a paso desde cero hasta la app instalada | **Léelo primero** |
| **`01-prerequisitos.md`** | Qué cuentas crear, qué instalar antes de empezar | Día 1 |
| **`02-prompt-claude-code.md`** | El prompt inicial para Claude Code | Cuando abras Claude Code |
| **`03-database-schema.sql`** | Esquema completo de PostgreSQL/Supabase | Lo ejecutas en Supabase |
| **`04-estructura-proyecto.md`** | Cómo se organiza el monorepo | Referencia |
| **`05-compilar-instalar.md`** | Pasos para compilar la app y meterla en tu móvil | Cuando la base esté lista |
| **`06-prompts-siguientes.md`** | Prompts ordenados para construir cada feature | Después del MVP base |
| **`07-comandos-utiles.md`** | Cheatsheet de comandos Git, Expo, etc. | Referencia diaria |

## 🎯 La ruta más corta

```
1. Lee 00-EMPIEZA-AQUI.md
2. Sigue 01-prerequisitos.md (instalar cosas, crear cuentas)
3. Ejecuta 03-database-schema.sql en Supabase
4. Abre Claude Code y pégale 02-prompt-claude-code.md
5. Sigue 05-compilar-instalar.md para verlo en tu móvil
6. Vuelve a Claude Code con los prompts de 06-prompts-siguientes.md
```

**Tiempo estimado hasta tener la app corriendo en tu móvil:** 3–5 horas el primer día.
